# 유튜브 제작 자료

이 폴더의 《하얀거탑》 영상과 관련 설명은 유튜브 영상 제작에 사용한다. 블로그 원고에는 장면 설명이나 영상 플레이어를 넣지 않는다.

## 《하얀거탑》 — “수술은 여기서 내가 통제하겠네!”

장준혁과 노민국이 수술 방법과 주도권을 두고 대립할 때, 참관실의 이주완 교수가 개입하는 장면이다. 출처는 [MBC 공식 영상의 약 2분 50초](https://www.youtube.com/watch?v=ke-jgZMIU6A&t=170s)다.

| 파일 | 길이 | 핵심 대사 시작 |
| --- | --- | --- |
| [전체 클립](./white-tower-surgery.mp4) | 3분 5초 | 약 2분 50초 |
| [대사 구간 발췌](./white-tower-control-line.mp4) | 12초 | 약 2초 |

발췌 파일은 전체 클립의 2분 48초부터 3분까지다.

내레이션 메모: 그 교수에게는 해당 분야의 경험과 인정받는 전문성이 있었다. 나는 프로젝트의 개발을 주도하면서도, 개발 경험이 없는 대표가 AI와 정한 기술과 작업 방향을 따라가야 했기 때문에 거부감을 느꼈다. 이 장면은 그 회고를 설명하는 유튜브 편집용 비유로 사용한다.
