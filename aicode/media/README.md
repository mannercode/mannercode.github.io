# 영상 원본·후보 자료

이 폴더에는 편집에 참고할 원본과 아직 본문에 쓰지 않은 영상을 둔다. 본문에 실제로 쓰는 편집본은 [1편 본문 자료](../../assets/ai-coding-part1/README.md)로 옮겼다.

## 부실공사 — 누수와 마감 하자

[하자 장면 모음](../../assets/ai-coding-part1/leaking-house-defects.mp4)은 인터뷰와 사람이 나오는 장면을 제외한 약 1분 7초의 무음 영상이다. 원본은 [주택 하자 영상](https://www.youtube.com/watch?v=_HjdVs9gjX4&t=164s)이다. 합류 당시 시스템을 물이 새는 집에 비유한 대목에 사용한다.

## 《하얀거탑》 — “수술은 여기서 내가 통제하겠네!”

장준혁과 노민국이 수술 방법과 주도권을 두고 대립할 때, 참관실의 이주완 교수가 개입하는 장면이다. 출처는 [MBC 공식 영상의 약 2분 50초](https://www.youtube.com/watch?v=ke-jgZMIU6A&t=170s)다.

| 파일 | 길이 | 핵심 대사 시작 |
| --- | --- | --- |
| [전체 클립](./white-tower-surgery.mp4) | 3분 5초 | 약 2분 50초 |
| [대사 구간 발췌](./white-tower-control-line.mp4) | 12초 | 약 2초 |

발췌 파일은 전체 클립의 2분 48초부터 3분까지다. 핵심 대사가 들리도록 원음을 유지했다. 현재는 참고자료로 보관한다.

블로그와 스토리보드에는 [저자가 직접 만든 약 10초 영상](../../assets/ai-coding-part1/grok-video-58178a05-0934-4955-8c0e-e25f58ee072f.mp4)을 사용한다. 오른쪽 위에 `mannercode`가 표시된 파일이며, 본문 자료 폴더로 옮겼다.

내레이션 메모: 그 교수에게는 해당 분야의 경험과 인정받는 전문성이 있었다. 나는 프로젝트의 개발을 주도하면서도, 개발 경험이 없는 대표가 AI와 정한 기술과 작업 방향을 따라가야 했기 때문에 거부감을 느꼈다. 이 장면은 그 회고를 설명하는 비유로 사용한다.
