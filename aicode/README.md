# AI 코딩 글 작업 안내

현재 1편은 [ai_coding_part1.md](./ai_coding_part1.md)에서 작성한다. 2편에서 다룰 새 생각은 [ai_coding_part2_notes.md](./ai_coding_part2_notes.md)에 모으고 있다.

기존의 세 초안은 중복되는 내용을 주제별 참고자료로 정리하고, 전체 원문은 `archive/`에 보관했다. 집필할 때는 아래 자료에서 필요한 사건과 논점을 찾고, 원래 문장이 필요하면 보관본을 확인하면 된다.

이 폴더의 원고·참고자료·보관본은 공개를 전제로 식별 정보를 일반화한다. 실제 서비스명과 저장소명은 역할 중심의 표현으로, 연락처와 도메인은 예시 값으로 바꾸고, 커밋 해시와 불필요한 지역명은 싣지 않는다. 기술명과 사례의 동작·검증 결과는 유지하며, 원래 이름과 대체 표기의 대응표는 이 폴더에 남기지 않는다.

발행 전에는 사건의 시점·인원·업무 범위·수치의 조합, 이미지와 첨부파일, 과거 Git 이력에서도 대상을 특정할 수 있는지 별도로 확인한다. 현재 파일의 명칭을 바꿨다는 사실만으로 완전한 익명성이 보장되지는 않는다.
