# AI 코딩 1편 — 세미나 발표

[최종 1편 원고](../ai_coding_part1.md)를 바탕으로 만든 세미나 자료다. 개발자와 대표 등 함께 제품을 만드는 청중에게 8개월의 경험과 당시의 판단을 공유한다. 구체적인 실천 방법과 해결 사례는 2편에서 다룬다.

| 파일 | 내용 |
| --- | --- |
| [세미나 PPT](./ai_coding_part1_seminar.pptx) | 편집 가능한 16:9 발표 자료. 본 발표 22장과 참고 슬라이드 3장 |
| [발표자 노트](./ai_coding_part1_seminar_notes.md) | 슬라이드별 설명, 예상 시간과 출처. 같은 설명을 PPT의 발표자 노트에도 포함 |

발표 27분과 질의응답 3분을 기준으로 구성했다. 23–25번은 질의응답 때 필요에 따라 사용하는 참고 자료다. 글꼴은 Apple SD Gothic Neo를 사용했다.

이미지는 [1편 첨부물](../attachments/README.md)을 사용하며 PPT 안에 포함돼 있다. 기존 유튜브 영상 구성안과 별도로 관리한다.
